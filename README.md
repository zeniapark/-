# HANARO CS Insight

한국어 고객상담 관리 플랫폼. Python 3.12+ 표준 라이브러리와 SQLite를 사용하며 별도 패키지 설치가 필요하지 않습니다.

## 권장 운영 방식: Cloudflare

회사 PC가 꺼져 있어도 고정 주소에서 실행되고 여러 사용자의 데이터가 계속 누적되는 배포판은 [`cloudflare`](cloudflare/) 폴더에 있습니다. Cloudflare Worker가 서버를 실행하고 D1 데이터베이스가 회원·상담 기록을 중앙 저장합니다. 처음에는 무료 계정으로 시작할 수 있으며, 무료 한도와 정책은 사용량 및 Cloudflare 정책에 따라 달라질 수 있습니다.

배포 절차와 첫 관리자 생성 방법은 [`cloudflare/README.md`](cloudflare/README.md)를 따릅니다. 기존 회사 PC용 Python 버전은 로컬 운영 및 데이터 이전용으로 함께 유지합니다.

## 회사 PC에서 무료로 실행

이 방식은 별도 호스팅 요금 없이 회사 PC 한 대를 서버로 사용합니다. 서버 PC가 켜져 있고 사이트 실행 창이 열려 있어야 다른 담당자가 접속할 수 있습니다.

### Windows

1. 서버로 사용할 회사 PC에 [Python 3](https://www.python.org/downloads/windows/)를 설치합니다. 설치 화면에서 **Add python.exe to PATH**를 선택합니다.
2. 이 프로젝트 폴더 전체를 서버 PC의 문서 폴더처럼 삭제되지 않는 위치에 복사합니다.
3. `run_windows.bat`을 더블 클릭합니다.
4. Windows 방화벽 창이 나타나면 **개인 네트워크**만 허용합니다. 공용 네트워크는 허용하지 않습니다.
5. 서버 PC에서는 `http://localhost:3000`으로 접속합니다.
6. 같은 사무실 네트워크의 다른 PC에서는 `http://서버PC의-IP주소:3000`으로 접속합니다. 서버 PC에서 `ipconfig`를 실행하면 `IPv4 주소`를 확인할 수 있습니다. 예: `http://192.168.0.25:3000`

처음 설치한 PC에서는 `setup_first_admin_windows.bat`을 한 번 실행하고 관리자 이메일을 입력합니다. 화면에 표시되는 `invitation_token`을 복사한 다음 사이트 회원가입 화면의 초대 코드에 입력하세요. 관리자 가입이 끝난 뒤에는 관리자 화면에서 13명의 일반 사용자 초대 링크를 한꺼번에 만들 수 있습니다.

실행 중 표시되는 검은 창을 닫으면 사이트도 종료됩니다. 서버 PC가 절전 모드에 들어가도 접속이 끊기므로 Windows 전원 설정에서 업무 시간 동안 절전을 해제하세요.

### Mac/Linux

```sh
chmod +x run_mac_linux.sh
./run_mac_linux.sh
```

기본 포트는 3000입니다. 초대받은 회원만 가입할 수 있습니다. 초대 링크를 연 뒤 해당 이메일, 영문·숫자·특수문자를 포함한 8~15자 비밀번호, 담당자 이니셜을 등록하세요. 테스트 계정이나 기본 비밀번호는 제공하지 않습니다.

### 데이터 백업

Windows에서는 `backup_windows.bat`을 더블 클릭합니다. 실행 중인 사이트를 중단하지 않고 `backups` 폴더에 검증된 백업을 만듭니다. 매일 한 번 실행하고, 생성된 백업 파일을 회사의 승인된 별도 저장장치에도 복사하세요. 실제 데이터는 `data/cs.sqlite3`에 있습니다. 프로젝트를 다른 PC로 옮길 때는 `data` 폴더를 반드시 함께 옮겨야 계정과 상담 기록이 유지됩니다.

### 접속 범위

- 같은 사무실 공유기/Wi-Fi에 연결된 PC: 추가 비용 없이 접속 가능
- 회사 밖의 PC나 휴대폰: 이 구성만으로는 접속 불가
- 인터넷 공유를 위해 공유기 포트 3000을 직접 개방하지 마세요. 이 프로그램은 사내 네트워크용 HTTP 구성입니다.

외부 접속이 꼭 필요하면 회사에서 승인한 VPN을 사용하거나, HTTPS를 제공하는 별도 호스팅으로 전환해야 합니다. VPN 제품의 무료·유료 여부와 회사 사용 조건은 해당 서비스 정책에 따릅니다.

## 비용 없는 외부 접속

`run_external_windows.bat`을 더블 클릭하면 회사 PC에서 사이트와 Cloudflare Quick Tunnel을 함께 실행합니다. 처음 한 번은 Cloudflare의 공식 터널 프로그램을 `tools` 폴더에 내려받습니다. 잠시 뒤 검은 창에 다음과 비슷한 HTTPS 주소가 표시됩니다.

```text
https://임의의-이름.trycloudflare.com
```

이 주소를 승인된 담당자에게 직접 전달합니다. 담당자는 별도 프로그램 없이 브라우저로 접속하고, HANARO의 승인된 계정으로 로그인합니다. 사이트의 회원가입은 관리자가 만든 이메일 전용 일회용 초대가 있어야 가능하며, 관리자가 사용자를 차단하면 기존 세션도 폐기됩니다. 로그인 실패는 동일 접속지에서 15분 동안 10회로 제한됩니다.

외부 접속을 중지하려면 검은 창에서 `Ctrl+C`를 누르거나 창을 닫습니다. 회사 PC가 꺼지거나 절전 상태가 되거나 창이 닫히면 사이트도 접속되지 않습니다.

무료 Quick Tunnel에는 다음 제약이 있습니다.

- 프로그램을 다시 실행할 때마다 공유 주소가 바뀔 수 있습니다.
- Cloudflare가 개발·시험 용도로 제공하는 기능이므로 운영 시간과 주소를 보장하지 않습니다.
- Cloudflare 계정이나 결제는 필요 없지만, 회사의 외부 서비스 사용 정책은 별도로 확인해야 합니다.
- 로그인 화면은 주소를 아는 사람에게 보일 수 있습니다. 상담 기록과 관리 기능은 승인된 로그인 계정에만 제공됩니다.
- 고정 주소와 운영 보장이 필요해지면 회사 도메인 또는 유료 호스팅으로 이전해야 합니다.

사내 접속용 `run_windows.bat`과 외부 접속용 `run_external_windows.bat`을 동시에 실행하지 마세요. 외부 접속 시에는 HTTPS 보안 쿠키를 사용하므로 검은 창에 표시되는 HTTPS 주소로 접속하세요.

- 메인 대시보드: 문의글·유선·반품·VOC·CS매뉴얼 통합 검색, 한국 시간 당일 집계, 마켓별·카테고리별 집계
- 기간 검색: 일자·월·분기·반기·연도·전체. 기준일이 속한 기간으로 검색합니다.
- 공통 검색: 마켓·담당자·카테고리·키워드·연락처·주문번호
- 문의글·유선·반품 등록 및 담당자별 통계
- 출고후반품 자동 기록, 내역 상세 보기, 검색 결과 CSV 다운로드
- VOC·CS매뉴얼 기본 등록·조회
- 등록·다운로드 담당자 감사 기록, 서버 측 세션, scrypt 비밀번호 해시

당일 전체 문의량은 문의글+유선+반품+VOC이며, 검색 조건을 함께 반영합니다. 마켓·카테고리·담당자 통계는 검색 기간 기준입니다. 날짜는 한국 시간 기준으로 자동 입력되며 등록 시 변경할 수 있습니다. 출고후반품의 착하반품은 '착하', 그 외 반품 코드는 '반품'으로 표시합니다.

## 데이터와 검증

DB는 기본 `data/cs.sqlite3`에 보관됩니다. `CS_DB`로 저장 위치를 변경할 수 있습니다. 이 파일을 안전하게 백업하세요. 테스트는 임시 DB에서 수행하므로 실제 데이터와 분리됩니다.

```sh
python3 -m unittest -v
node --check static/app.js
```

## 비공개 공유와 관리자·사용자 모드

주소를 아는 것만으로는 업무 기록을 조회하거나 다운로드할 수 없습니다. 로그인 화면은 공개 주소에서 열리지만, 유효한 초대와 승인된 계정이 있어야 업무 API를 사용할 수 있습니다. 검색엔진에는 HTML 메타 태그, 응답 헤더, robots.txt로 비노출을 요청합니다. 검색엔진 비노출은 인증을 대체하지 않습니다.

| 역할 | 기능 |
| --- | --- |
| 관리자 | 사용자 업무 + 관리자 모드에서 회원 초대·초대 취소·가입 승인·접근 차단 |
| 사용자 | 공통 업무 기록 검색·등록·통계 조회·CSV 다운로드 |

관리자는 상단의 **관리자 모드 / 사용자 모드** 버튼으로 화면을 전환합니다. 일반 사용자에게는 이 버튼이 없으며, 관리자 API도 서버에서 거부합니다. 현재는 승인된 팀원끼리 업무 기록을 함께 조회합니다. 역할은 화면에서 임의로 변경할 수 없고, 추가 관리자 지정은 로컬 운영자 명령으로만 수행합니다.

### 첫 관리자 지정

새 DB에서는 자동으로 관리자 계정이 생성되지 않습니다. 호스팅 서버의 비공개 콘솔에서 다음 명령으로 실제 운영자 이메일의 첫 초대를 발급합니다.

```sh
python3 manage.py invite owner@example.com --admin
```

출력 JSON의 `invitation_token`을 가입 화면의 초대 코드에 입력하고, 같은 이메일로 가입합니다. 이 값은 일회용 가입 자격이므로 공개 로그나 소스에 저장하지 마세요. 또는 사이트 주소의 `/#invite=발급된코드&email=초대한이메일` 형식으로 링크를 만들어 전달할 수 있습니다. 토큰은 URL fragment로 전달하며 브라우저가 읽은 뒤 주소에서 제거합니다. 서버에는 토큰 해시만 저장합니다.

가입한 관리자는 화면에서 담당자별 이메일로 일반 회원 초대 링크를 만들고 복사할 수 있습니다. 초대는 지정 이메일에만 유효하며, 7일 뒤 만료되고 가입 시 한 번만 사용됩니다. 링크를 받은 사람이 해당 이메일의 소유자인지 이메일 발송으로 검증하지는 않으므로, 초대 링크를 해당 담당자에게만 안전하게 전달하세요. 이메일은 자동 발송되지 않습니다.

### 기존 DB에서 전환

기존 계정·업무 데이터는 보존됩니다. 다만 기존 계정은 승인 대기 상태로 전환되어, 운영자가 명시적으로 승인하기 전에는 기존 세션과 비밀번호로 접근할 수 없습니다. 최초 기존 관리자는 로컬 콘솔에서 승인합니다.

```sh
python3 manage.py approve owner@example.com --admin
```

그 뒤 관리 화면에서 다른 기존 회원을 승인하면 됩니다. 계정 차단 시 기존 세션을 폐기합니다. 재승인 후 다시 로그인해야 합니다. 자기 계정이나 마지막 관리자를 차단할 수 없습니다. 전환 전에 DB를 백업하고 보존하세요.

## 운영 전 확인

회사 PC 운영은 소규모 사내 네트워크용입니다. 공용 Wi-Fi나 인터넷에 직접 노출하지 마세요. 외부 공유에는 HTTPS, 운영용 프록시/서버, 로그인 시도 제한과 회사 보안 정책 검토가 필요합니다. HTTPS 배포 시 `CS_SECURE_COOKIE=1`을 설정하세요. 이메일 인증·비밀번호 재설정·리포트 메일 발송은 아직 구현하지 않았습니다.
